# 🧰 Sistem Tiketing Laporan IT

Aplikasi berbasis web yang dikembangkan selama masa magang di **Pengadilan Negeri Medan**.  
Proyek ini bertujuan untuk membantu bagian IT dalam mengelola laporan kerusakan atau permasalahan teknis secara terstruktur dan efisien melalui sistem tiket online.

---

## 🚀 Fitur Utama

- **Manajemen Tiket:** Pengguna dapat membuat laporan masalah IT yang otomatis tersimpan dalam sistem.
- **Autentikasi Pengguna:** Tersedia login & registrasi dengan level akses (Admin & Pengguna).
- **Chat Realtime:** Fitur komunikasi langsung antara pelapor dan admin terkait status laporan.
- **Status Laporan:** Setiap laporan dapat dipantau berdasarkan status (Baru, Diproses, Selesai).
- **Dashboard Admin:** Admin dapat memantau jumlah laporan, status, dan aktivitas pengguna.
- **Dokumentasi & Riwayat:** Semua laporan tersimpan sebagai arsip untuk evaluasi selanjutnya.

---

## 🛠️ Teknologi yang Digunakan

- **Framework:** Laravel 11 
- **Database:** MySQL  
- **Frontend:** Blade Template, Bootstrap CSS
- **Server:** PHP 8.2
- **Version Control:** Git & GitHub
